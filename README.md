# AxiomHUB

by kingping77 · Slayers 2 (menu + Ouwigahara) · Murder Mystery 2

## Slayers 2

```lua
getgenv().SlayersConfig = {
	AutoQueue = false,
	AutoJoinPrivate = false,
	Farm = true,
	AutoStart = true,
	LoopRuns = true,
	AutoShop = true,
}
loadstring(game:HttpGet("https://raw.githubusercontent.com/oTheShad4w/Axiomus/main/AxiomHUB.lua"))()
```

## Murder Mystery 2

```lua
getgenv().MM2Config = {
	AutoFarm = true,
	AltMode = false,
}
loadstring(game:HttpGet("https://raw.githubusercontent.com/oTheShad4w/Axiomus/main/AxiomHUB.lua"))()
```

The config block is optional, without it the hub uses its saved settings.
