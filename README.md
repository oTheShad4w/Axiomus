Free работает сразу, без ключа. Для Premium укажи ключ перед загрузкой:

```lua
getgenv().script_key = "ТВОЙ-КЛЮЧ"
```

Ключ выдаёт наш Discord-бот. Config-блок необязателен — без него хаб берёт сохранённые настройки.
